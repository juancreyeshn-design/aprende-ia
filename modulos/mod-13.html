📊 Módulo 13. Dashboards profesionales con Lovable

📘 Concepto

Una hoja de cálculo cumple su función, pero tiene límites: es difícil de compartir con quien no sabe leer fórmulas, no tiene acceso controlado y actualizarla significa reenviar el archivo cada vez. Lovable resuelve los tres problemas a la vez — transforma cualquier hoja de cálculo en un panel de control alojado en internet, con una URL pública, un área para subir nuevos datos y, si lo pides, una pantalla de acceso. Todo esto sin escribir una línea de código: describes en texto lo que quieres ver y Lovable construye la aplicación completa.

Cómo acceder:

  • 01 — Accede: entra a lovable.dev desde el navegador, no necesita instalación.
  • 02 — Cuenta: crea una cuenta gratuita con correo electrónico o GitHub.
  • 03 — Plan: el plan gratuito permite hasta 5 proyectos con limitaciones de generación; el plan Pro (US$ 25/mes) da proyectos ilimitados y generación sin restricción.

El proceso completo son 3 etapas, y cada una es un prompt independiente dentro del mismo proyecto de Lovable:

  • Etapa 1 — Panel de control: pegas o describes el contenido de tu hoja de cálculo y pides el dashboard. Resultado: panel visual funcionando con tus datos reales, alojado con URL pública.
  • Etapa 2 — Área de carga: pides una página para subir un nuevo CSV en el mismo formato. Resultado: al subir el archivo, el panel se actualiza automáticamente con los datos nuevos.
  • Etapa 3 — Acceso: pides una pantalla de login. Resultado: solo quien tiene cuenta creada accede al panel de control.
💡 La regla de oro del archivo: Lovable lee archivos CSV, y el formato debe ser siempre idéntico en cada actualización — los mismos nombres de columna, en el mismo orden. Es lo que permite que la aplicación lea y actualice el panel automáticamente, sin configuración adicional. Si el orden cambia, la app no puede leer los datos correctamente.

⚡ Caso aplicado: de hoja de cálculo a app en 3 prompts

Ejemplo completo con un control financiero personal — la misma estructura de columnas del Módulo 12 (Fecha, Descripción, Categoría, Tipo, Monto) se reutiliza aquí como fuente de datos.

Prompt 01 — panel de control a partir del archivo: "Tengo un archivo CSV con datos de transacciones financieras. Las columnas son: Fecha, Descripción, Categoría (Alimentación / Transporte / Ocio / Salud / Vivienda / Otros), Tipo (Ingreso o Gasto), Monto. Aquí están los datos: [PEGA EL CONTENIDO DE TU CSV AQUÍ]. Crea un dashboard limpio y moderno que lea estos datos y muestre: 4 tarjetas de KPI en la parte superior — Ingresos Totales, Gastos Totales, Saldo Actual y Tasa de Ahorro %. Un gráfico de barras que compare Ingresos vs Gastos por mes. Un gráfico de dona que muestre el desglose de gastos por categoría. Una tabla que liste las 10 transacciones más recientes. Usa un tema oscuro con detalles en morado. Hazlo totalmente responsivo para que también funcione en celular.
Prompt 02 — área de carga para actualizar los datos: "Agrega una página de 'Actualizar Datos' a la app. Esta página debe tener un área simple de carga de archivos donde yo pueda arrastrar y soltar o seleccionar un nuevo archivo CSV en el mismo formato que el original (columnas: Fecha, Descripción, Categoría, Tipo, Monto). Cuando suba el nuevo archivo, la app debe leerlo, reemplazar los datos actuales con los nuevos y actualizar automáticamente el dashboard con las cifras y los gráficos actualizados. Muestra un mensaje de éxito después de la carga confirmando cuántos registros se cargaron. Agrega un enlace de navegación entre el Dashboard y la página de Actualizar Datos."
Prompt 03 — acceso y control de acceso: "Agrega una pantalla de login simple para proteger la app. Crea una página de login con campos de email y contraseña y un botón de Iniciar Sesión. Yo crearé las cuentas de usuario manualmente — no se necesita registro público. Después del login, redirige al Dashboard. Si el usuario no inició sesión, redirige a la página de Login. Agrega un botón de cerrar sesión en la esquina superior de cada página. Mantén el mismo diseño oscuro en morado. Usa Supabase Auth para la autenticación."

Cómo actualizar el panel en el futuro — una vez la app está en el aire, ya no se vuelve a abrir Lovable. El flujo se repite en 3 pasos simples:

  1. Prepara el archivo: exporta la hoja de cálculo actualizada como CSV, con el mismo formato de siempre. Puede tener más filas que el original — la aplicación las lee todas.
  2. Sube el archivo: abres el enlace de la app, vas a la página "Actualizar Datos" y arrastras el nuevo CSV al área de carga.
  3. Confirmación: la app reemplaza los datos antiguos con los nuevos y muestra un mensaje de éxito con el número de registros cargados. El dashboard ya refleja los datos actualizados.
✅ Buenas prácticas Exporta siempre como CSV antes de subir o pegar los datos — un .xlsx directo de Excel puede no funcionar. Envía los 3 prompts uno por vez, esperando a que Lovable termine cada etapa: la carga de datos depende del dashboard ya construido, y el login depende de las páginas ya creadas. Describe los gráficos de forma específica ("gráfico de dona de gastos por categoría", no "algunos gráficos"). Prueba la carga de un archivo de actualización antes de compartir el enlace con otras personas.
⚠️ Errores comunes Subir un nuevo CSV con las columnas en otro orden (la app no puede leer los datos), enviar los 3 prompts de una sola vez (genera conflictos y resultados incompletos), olvidar exportar como CSV antes de subir, escribir un prompt sin describir los gráficos específicos que se quieren ver, y no probar la carga de un archivo antes de pasar el enlace a otros usuarios.
💡 El mismo flujo de 3 prompts sirve para cualquier tipo de panel — financiero, de ventas, de metas o de proyectos. Lo único que cambia es la estructura de columnas del CSV y los indicadores que le pides a Lovable que muestre.
