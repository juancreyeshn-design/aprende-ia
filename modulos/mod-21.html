🔌 Módulo 21. APIs de IA: la puerta de entrada

📘 Concepto

Usas Claude por el sitio web, ChatGPT por la app. Pero existe una forma mucho más poderosa de usar esas IAs: conectándolas directamente a otros programas, automatizaciones y herramientas. Esa conexión se llama API (Application Programming Interface) — olvida la sigla, lo que importa es el concepto: es la forma en que dos programas conversan entre sí para hacer un pedido y recibir una respuesta.

La analogía del restaurante: imagina que estás en un restaurante. Tú (el cliente) no entras a la cocina a hacer la comida — haces un pedido al mesero. El mesero lleva el pedido a la cocina, que prepara y devuelve; no sabes cómo se hizo la comida, solo que pediste y recibiste. La API es el mesero: haces un pedido (la pregunta para la IA), la API lo lleva al servidor de la empresa, el servidor procesa y devuelve la respuesta.

💡 Sitio web es manual, API es automática. Cuando abres claude.ai y envías un mensaje, el sitio web usa la API de Claude por debajo. Cuando una automatización en n8n envía un texto a Claude para analizar, usa la misma API. La diferencia: por el sitio web la usas manualmente, una vez por vez; por la API, los programas y automatizaciones la usan automáticamente, cuantas veces quieran — eso es lo que la API libera: escala, automatización e integración con cualquier herramienta.

API key — la clave que abre la puerta: para usar la API de cualquier IA necesitas una API key: una contraseña única en forma de código, generada por la empresa, que te identifica cada vez que un programa usa la IA en tu nombre. La empresa registra el uso y cobra en tu cuenta. Trátala como una contraseña bancaria: no la compartas con nadie, no la pongas en textos públicos ni en GitHub, no la envíes por WhatsApp. Si alguien la obtiene, puede usar la IA en tu nombre y tú pagas la cuenta — si sospechas que fue expuesta, ve al panel de la empresa y cancélala; puedes generar otra en cualquier momento. Crear la clave es gratis en todas las empresas — solo pagas por el uso (en tokens, como se vio en el Módulo 20); la mayoría ofrece créditos gratuitos iniciales para empezar a probar sin gastar nada.

⚡ Caso aplicado: crear tu clave y elegir la API correcta

El proceso para crear una API key es parecido en todas las empresas: acceder al panel, entrar en la cuenta, ir a "API Keys", crear la clave y guardarla de inmediato — en la mayoría de los servicios la clave aparece una sola vez.

Claude (Anthropic) — console.anthropic.com: 1) Accede a la consola. 2) Crea una cuenta con 'Sign Up' (o usa tu inicio de sesión de claude.ai). 3) Ve a 'API Keys' en el menú lateral. 4) Haz clic en 'Create Key', dale un nombre (ej. 'mi-automatización') y confirma. 5) Copia y guarda la clave de inmediato. ChatGPT (OpenAI) — platform.openai.com: mismo flujo, en 'API Keys' o platform.openai.com/api-keys, con 'Create new secret key'. Gemini (Google) — aistudio.google.com: inicia sesión con tu cuenta Google, ve a 'Get API key' → 'Create API key' y vincúlala a un proyecto (puedes crear uno nuevo con cualquier nombre).

Qué API usar según la tarea — cada empresa tiene sus fortalezas:

  • Anthropic (Claude) — console.anthropic.com — mejor para razonamiento profundo, análisis de documentos largos y agentes complejos.
  • OpenAI (GPT-4o · GPT-4o mini) — platform.openai.com — uso general, integraciones con herramientas y volumen alto con costo bajo.
  • Google (Gemini 1.5 Flash · Pro) — aistudio.google.com — volumen extremo con costo mínimo y contexto muy largo (1 millón de tokens).
  • Groq (Llama 3 · Mixtral) — console.groq.com — velocidad extrema, respuestas en tiempo real y modelos open source.
  • Mistral — console.mistral.ai — alternativa europea, buena relación costo-beneficio para producción.

Como referencia rápida de decisión: para alto volumen (Gemini Flash · GPT-4o mini) la velocidad y la relación costo-beneficio son excelentes pero la profundidad es baja; para profundidad (Claude Sonnet · Opus) la capacidad de análisis es máxima pero cuesta más y es más lento; para tiempo real (Groq + Llama 3) la velocidad es la mayor de todas; y para costo cero para probar (Gemini Flash con créditos gratis) la relación costo-beneficio es excelente sin gastar nada al empezar.

Cómo funciona una llamada a la API, paso a paso:

  1. El programa envía el pedido (API key + modelo + texto) — cualquier herramienta que usa IA (n8n, Zapier, un sitio) envía un mensaje a la API de la empresa con la clave, el modelo a usar (Claude Sonnet, GPT-4o, etc.) y el texto a procesar.
  2. La API verifica la key y llama al modelo de IA — el servidor recibe la solicitud, verifica la clave y envía al modelo especificado.
  3. El modelo genera la respuesta — todo esto ocurre en milisegundos.
  4. La API devuelve la respuesta + el conteo de tokens — el conteo sirve para calcular el costo.
  5. El programa usa la respuesta como quiera: la guarda en una hoja de cálculo, la envía por correo, la publica en un sitio, la envía por WhatsApp. La API no sabe ni le importa qué se hace con la respuesta — solo la entrega.
✅ Buenas prácticas Trata la API key como una contraseña bancaria: nunca la compartas, ni la subas a GitHub ni la envíes por WhatsApp. Cópiala y guárdala de inmediato al crearla, en un gestor de contraseñas o documento seguro — en la mayoría de los servicios aparece una sola vez. Configura un límite de gasto mensual en el panel de la empresa antes de poner en marcha automatizaciones. Usa Claude Haiku o Sonnet (o Gemini Flash, GPT-4o mini) para automatizaciones del día a día, y reserva los modelos más caros (Opus) para análisis realmente complejos.
⚠️ Errores comunes Compartir la API key públicamente; no guardarla en el momento de la creación (cuando ya no se puede recuperar); usar el modelo más caro (como Claude Opus) para todo sin pensar en el costo; no configurar un límite de gasto en el panel, arriesgando una sorpresa en la factura; y confundir la API con el sitio web — son canales diferentes, con precios y formas de acceso distintas: el sitio (claude.ai) es para uso manual, uno por vez; la API es para que los programas la usen automáticamente.
