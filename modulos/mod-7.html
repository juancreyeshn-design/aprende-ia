📊 Módulo 7. Excel + IA: planillas y análisis financiero

📘 Concepto

ChatGPT, Claude y Gemini no se quedan en el chat: los tres pueden generar archivos funcionales —planillas con fórmulas, dashboards con gráficos, conciliaciones ya estructuradas— listos para abrir en Excel o Google Sheets. En vez de construir la estructura desde una hoja en blanco, le describes lo que necesitas y la IA entrega un primer borrador completo que tú revisas y ajustas.

  • Planillas con fórmulas: totales, subtotales, promedios y validaciones ya calculados, con formato profesional (encabezados, colores, moneda).
  • Dashboards de indicadores: resúmenes visuales con gráficos a partir de una tabla de datos que le proporcionas o describes.
  • Conciliaciones y controles: estructuras para cruzar dos fuentes (por ejemplo, libros contra banco) con las diferencias resaltadas automáticamente.
  • Plantillas reutilizables: una vez que un formato te funciona, lo guardas y solo cambias los datos en cada cierre.
💡 Idea clave: mientras más específico seas sobre las columnas exactas, los totales que necesitas y qué debe destacarse visualmente (por ejemplo, una partida fuera de rango), mejor será el primer borrador que recibas — y menos ajustes tendrás que hacer tú después.

⚡ Caso aplicado

Ejemplo de prompt para una conciliación bancaria: "Crea una planilla de conciliación bancaria con columnas para fecha, descripción, cargo, abono, saldo según libros y saldo según banco. Agrega una fila de totales al final y destaca visualmente las partidas que no coincidan entre ambos saldos."
✅ Buen uso Crear el borrador de una plantilla repetitiva (conciliaciones, control de gastos, flujo de caja), pedir que explique la lógica de una fórmula compleja, o generar un dashboard inicial a partir de una tabla de datos que tú aportas.
⚠️ Usar con cuidado Nunca subas una base de datos completa con información identificable de clientes sin anonimizar primero. Y antes de usar en un informe real cualquier fórmula o total generado por IA, verifícalo con un cálculo de control manual — la responsabilidad sobre la cifra que entregas sigue siendo tuya.
