🧩 Módulo 22. Usando API sin programar

📘 Concepto

En el módulo anterior viste qué es una API y para qué sirve una API key. Pero conectar la API de una IA a tus herramientas de trabajo no requiere saber programar: existen plataformas visuales, "de arrastrar y soltar", que conectan la API con tus aplicaciones (correo, hojas de cálculo, WhatsApp, formularios) sin escribir una sola línea de código. Al usar una de estas herramientas, tu trabajo cambia de naturaleza: dejas de ejecutar la tarea manualmente cada vez y pasas a configurar el flujo una vez y revisarlo — te conviertes en el revisor y responsable del proceso, no en quien lo hace a mano.

Cinco herramientas no-code principales, cada una con su propio punto fuerte:

  • n8n — gratuito (auto-alojado) o desde US$20+/mes en su versión en la nube; da más control y personalización. Conviene para quien ya se siente cómodo con automatizaciones y quiere flujos más a la medida sin pagar una mensualidad alta.
  • Make — plan gratis con 1.000 operaciones al mes; interfaz visual "de burbujas" conectadas y más de 1.500 integraciones disponibles.
  • Zapier — plan gratis con 5 Zaps y 100 tareas al mes; es la opción más simple de las cinco y la que tiene más soporte y comunidad en español, ideal para empezar.
  • Google Sheets + Apps Script — completamente gratis; permite crear una función personalizada, por ejemplo =CLAUDE(), que se usa celda por celda dentro de la propia hoja de cálculo, sin salir de Sheets.
  • Typebot — plan básico gratis, plan Starter desde US$39/mes; sirve para construir chatbots visuales conversacionales.
💡 No hace falta dominar las cinco. Para alguien que recién comienza, la recomendación es clara: empieza con Zapier o Make por ser las más simples, y migra a n8n solo cuando ya te sientas cómodo y necesites más control.

⚡ Caso aplicado: 5 usos reales sin escribir código

Estos son cinco flujos reales que se arman conectando una de estas herramientas con la API de una IA — adaptables a un despacho contable o una práctica profesional:

CASO 01 — Clasificar correos por urgencia (n8n o Make) Disparador: llega un correo nuevo a la bandeja de entrada. Acción de la IA: lee el asunto y el cuerpo del correo y responde SOLO con una etiqueta de urgencia, en formato fijo para que el flujo la pueda usar después, por ejemplo: {"urgencia": "alta" | "media" | "baja", "motivo": "..."} Resultado: el flujo mueve o etiqueta el correo según la urgencia devuelta, sin que nadie lo revise uno por uno. CASO 02 — Resumir reuniones grabadas automáticamente (n8n) Disparador: se sube una grabación o transcripción de una reunión a una carpeta. Acción de la IA: genera un resumen estructurado con puntos clave, decisiones tomadas y tareas pendientes con responsable, siempre en el mismo formato. Resultado: el resumen se guarda automáticamente y se puede enviar por correo a los participantes. CASO 03 — Responder evaluaciones/reseñas de Google (Zapier) Disparador: llega una reseña nueva en el perfil de Google del negocio. Acción de la IA: clasifica la reseña (positiva o negativa) y redacta una respuesta profesional y empática, en el tono de la empresa. Resultado: la respuesta se publica o queda lista para revisar y aprobar antes de publicarse. CASO 04 — IA directamente en Google Sheets (Apps Script) — el más útil para trabajo contable en Excel/Sheets Disparador: ninguno — se usa como una función más dentro de la hoja de cálculo. Acción de la IA: a partir de una celda con datos (una descripción de gasto, una partida contable), la función personalizada =CLAUDE(celda, "instrucción") devuelve en otra celda, por ejemplo, la cuenta contable sugerida o una clasificación, calculada fila por fila igual que una fórmula normal. Resultado: se clasifican cientos de filas de datos sin copiar y pegar en un chat una por una. CASO 05 — Chatbot de calificación de leads (Typebot) Disparador: un visitante inicia una conversación en el chatbot del sitio web. Acción de la IA: hace preguntas de calificación (presupuesto, necesidad, urgencia) y decide si el lead es prioritario. Resultado: los leads calificados como prioritarios se envían automáticamente al equipo de ventas.

Conectar la API key como credencial en n8n, paso a paso (el mismo principio aplica en Make, Zapier y las demás herramientas):

  1. Abrir Credentials — en el menú lateral de n8n, entrar a la sección de credenciales.
  2. Add Credential — buscar el proveedor por nombre, por ejemplo "Anthropic" u "OpenAI".
  3. Pegar la API key y darle un nombre — el nombre sirve para identificarla dentro de tus flujos (por ejemplo, "Claude - cuenta principal").
  4. Usar la credencial guardada en cualquier flujo — cada vez que un nodo necesite conectarse a esa IA, seleccionas la credencial ya guardada, sin volver a escribir la clave.
✅ Buenas prácticas Comienza con Zapier o Make, que son las más simples; migra a n8n cuando te sientas seguro y necesites más control. Configura las credenciales (API keys) de todas las IAs antes de crear cualquier flujo. La key va siempre en el sistema de credenciales de la herramienta, nunca escrita dentro del texto del prompt. Usa la función de prueba (Test Step o Test Workflow) antes de activar, y verifica que la respuesta se guarda correctamente. Dentro de un flujo automático no hay conversación de ida y vuelta — el prompt debe ser completo, específico y decir exactamente el formato en que debe llegar la respuesta.
⚠️ Errores comunes Intentar usar una herramienta compleja desde el inicio en vez de empezar simple; no configurar la API key en las credenciales de la herramienta; dejar la API key visible dentro del prompt en el flujo; crear flujos y activarlos sin probar primero con datos reales; y pedirle a la IA algo muy vago en el prompt de la API, olvidando que ahí no hay chat para aclarar después.
— Anotado por EDI: en un flujo automático, el prompt hace todo el trabajo de una sola vez. Sé tan específico como si le estuvieras dando instrucciones a alguien que solo va a leer el mensaje una vez y no puede preguntar nada más.
