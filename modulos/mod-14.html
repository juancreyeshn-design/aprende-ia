🚀 Módulo 14. Landing pages con Claude + Lovable

📘 Concepto

Una landing page que convierte no nace de un solo prompt improvisado: nace de separar el pensamiento estratégico de la construcción técnica. La fórmula es "Claude piensa, Lovable construye" — un flujo de 4 etapas donde las 3 primeras ocurren en Claude y la última en Lovable, y cada etapa alimenta a la siguiente.

  • Etapa 1 — Identidad, copy y embudo (Claude): describes tu producto y Claude entrega el posicionamiento, la persona (cliente ideal), el copy completo sección por sección (headline, beneficios, prueba social, FAQ, precio, CTA) y la estructura del embudo — qué pasa después del clic en el botón.
  • Etapa 2 — Sistema de diseño (Claude): con el copy ya definido, Claude arma la ficha de diseño — paleta de colores con códigos HEX exactos, tipografía, tamaños, radio de bordes, sombras y una referencia visual — lista para que Lovable la aplique sin inventar ni interpretar.
  • Etapa 3 — Prompt final (Claude): Claude organiza el copy y el sistema de diseño en un único prompt estructurado por secciones, listo para pegar en Lovable. Nada se pierde en la traducción, y el prompt generado se vuelve una plantilla reutilizable para futuras páginas.
  • Etapa 4 — Construcción (Lovable): pegas el prompt final en Lovable. Él aplica el copy y el sistema de diseño exactamente como se definieron y publica la página alojada, con URL pública.
💡 Ir directo a Lovable sin pasar antes por Claude entrega una página técnicamente funcional pero estratégicamente vacía — texto genérico y diseño predeterminado. Cuando Claude hace el trabajo estratégico primero, Lovable recibe un brief completo y ejecuta con precisión: cada herramienta hace lo que hace mejor.

⚡ Caso aplicado: los 3 prompts de Claude + el prompt final

Ejemplo completo de página de venta para un curso o servicio profesional propio.

Prompt 01 — identidad, copy y embudo (en Claude): "Eres un copywriter senior y estratega de marca. Necesito una estrategia completa de landing page para mi producto. Aquí está el contexto: [DESCRIBE TU PRODUCTO EN 3-5 ORACIONES — qué es, para quién, qué problema resuelve y qué lo hace diferente]. A partir de esto, entrega en formato estructurado: 1) Perfil del cliente ideal, 2) Declaración central de posicionamiento (una oración que capture el valor único), 3) Copy completo de la landing sección por sección — Titular (headline) y subtítulo del Hero, Beneficios (3 con título y descripción), Prueba social (2 testimonios realistas), FAQ (3 objeciones respondidas), Precio (una oferta con lo que incluye) y el texto del botón de CTA, 4) Estructura del embudo (funnel) — qué pasa después del clic en el CTA y qué debe decir la página de agradecimiento. Escribe todo el copy en español. Hazlo específico, persuasivo y alineado con el perfil del cliente."
Prompt 02 — sistema de diseño (en Claude): "Ahora crea el design system completo para esta landing page. Basándote en el posicionamiento del producto y el perfil de cliente que definimos, sugiere una identidad visual que conecte con esta audiencia. Entrega: 1) Paleta de colores con códigos HEX exactos — color primario (botones y CTAs), color secundario, color de fondo, color de superficie (cards y secciones), color de texto primario y color de texto secundario. 2) Tipografía — familia tipográfica para títulos, familia tipográfica para el cuerpo, tamaños de fuente para H1 / H2 / H3 / cuerpo / caption, y pesos tipográficos. 3) Estilo de los componentes — radio de borde de los botones, radio de borde de los cards, espaciado entre secciones y estilo de sombra. 4) Tono visual — una frase que describa la personalidad visual general. 5) Una referencia de layout — en qué sitio o marca reconocida se inspira este diseño. Formatea todo como una ficha de especificación estructurada, lista para pegar en un prompt de Lovable."
Prompt 03 — prompt final para Lovable (en Claude): "Ahora combina todo lo que creamos — el copy de la landing page y el design system — en un único prompt completo para Lovable. El prompt debe indicarle a Lovable que construya una landing page totalmente funcional y responsiva, usando exactamente el copy y el design system que definimos. Estructura el prompt de Lovable con estas secciones: 1) Resumen del proyecto — para qué es la página y el tono visual. 2) Design system — pega todos los colores, fuentes y estilos de componentes con sus valores exactos. 3) Estructura de la página — lista cada sección en orden con el copy exacto de cada una. 4) Requisitos técnicos — layout responsivo para móvil, smooth scroll, header fijo (sticky), comportamiento del botón de CTA. 5) Hosting — publica la página y proporciona la URL pública. Haz el prompt lo suficientemente detallado para que Lovable no tenga ningún motivo para improvisar ni inventar nada. Entrega solo el prompt final de Lovable, listo para pegar."
✅ Buenas prácticas Describe el producto con el máximo detalle posible en el Prompt 1 — audiencia, diferencial y qué siente el cliente antes y después de usarlo. Usa siempre los códigos HEX exactos del design system en el prompt de Lovable, nunca los dejes a su criterio. Si el texto necesita cambiar después de publicada la página, vuelve a Claude y regenera el prompt — no lo edites a mano dentro de Lovable. No te saltes la etapa del sistema de diseño: es lo que diferencia una landing con identidad propia de una genérica.
⚠️ Errores comunes Ir directo a Lovable sin pasar antes por Claude, describir el producto de forma vaga en el Prompt 1, no usar los códigos HEX exactos en el prompt de Lovable (deja que invente los colores), intentar ajustar el texto dentro de Lovable después de publicado en vez de regenerar el prompt en Claude, y saltarse la etapa del design system dejando que Lovable aplique su visual predeterminado.
💡 El prompt final que genera Claude en la Etapa 3 se vuelve una plantilla reutilizable: la próxima vez que necesites una landing page, solo cambias el contenido (producto, persona, copy) y repites el mismo flujo de 4 etapas.
