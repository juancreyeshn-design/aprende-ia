💬 Módulo 24. Asistente de IA en WhatsApp

📘 Concepto

Imagina mandar un mensaje por WhatsApp y recibir en segundos una respuesta inteligente y personalizada — no un bot de menú con opciones numeradas, sino un asistente real que entiende lo que pediste y responde como una persona. Esto se arma conectando tres piezas:

  • Evolution API — el conector de WhatsApp. WhatsApp no tiene API oficial para uso individual, así que Evolution API es una solución open source y gratuita que conecta tu número a internet. Se instala en un servidor propio (Railway y Render tienen planes gratuitos suficientes para comenzar).
  • n8n — el cerebro del flujo. Recibe el mensaje que llegó por Evolution API, lo envía a Claude para procesar, toma la respuesta y la manda de vuelta por WhatsApp.
  • Claude — la inteligencia. Procesa el mensaje según el system prompt configurado y genera la respuesta. Claude no sabe que está en WhatsApp — para él es solo otra conversación.

Todo esto sucede en menos de 5 segundos: para quien recibe el mensaje, parece una conversación normal con una persona.

💡 El límite de lo que el asistente puede hacer no es técnico, es el system prompt que le escribas. Ahí defines su personalidad, su tono y qué puede y qué no puede hacer.

⚡ Caso aplicado: monta tu asistente

Cuatro tipos de asistente según lo que necesites — el mismo flujo técnico sirve para los cuatro, solo cambia el system prompt:

01 · ASISTENTE DE PRODUCTIVIDAD Mandas: "Resumen de la reunión de hoy: [texto]" → devuelve un resumen con decisiones y próximos pasos. Mandas: "Crea una respuesta profesional para este email: [texto]" → recibes el borrador listo para enviar. 02 · ASISTENTE DE VENTAS Mandas: "El cliente preguntó sobre el plazo de entrega, ¿cómo respondo?" → sugiere el mejor enfoque. Mandas: "Necesito argumentos para rebatir la objeción de precio" → recibes 3 enfoques diferentes. 03 · ASISTENTE DE CONTENIDO Mandas un tema → genera la leyenda, los hashtags y la sugerencia visual. Mandas una idea → la transforma en un post o guion de reel estructurado. 04 · ASISTENTE FINANCIERO PERSONAL — el más útil para el control diario de gastos Mandas: "Gasté US$ 45 en el almuerzo, categoría alimentación" → registra el gasto y devuelve el saldo del mes, integrado con tu hoja de cálculo. Mantiene el control en tiempo real solo con mensajes de WhatsApp.

El system prompt define la personalidad — dos ejemplos completos y listos para adaptar:

SYSTEM PROMPT — ASISTENTE DE PRODUCTIVIDAD "Eres mi asistente personal en WhatsApp. Tu nombre es [NOMBRE DEL ASISTENTE]. Me ayudas con tareas de productividad, comunicación y organización. Reglas: 1) Respuestas cortas y directas — máximo 5 líneas, a menos que te pida más. 2) Tono informal y cercano — como un asistente de confianza, no un robot. 3) Cuando recibas un correo para redactar respuesta, entrega listo para copiar y pegar. 4) Cuando recibas texto de reunión, entrega resumen con decisiones y próximos pasos. 5) Si no entiendes lo que te pedí, pregunta antes de adivinar. 6) Nunca inventes información. Si no sabes, di que no sabes." SYSTEM PROMPT — ASISTENTE DE VENTAS "Eres mi asistente de ventas en WhatsApp. Me ayudas con atención al cliente, objeciones y negociaciones. Contexto de mi negocio: [PRODUCTO O SERVICIO, PRECIO, PÚBLICO Y DIFERENCIALES]. Reglas: 1) Ante una situación con cliente, sugiere el mejor enfoque en 3 líneas. 2) Ante una objeción, entrega 2 enfoques diferentes. 3) Ante un pedido de script, entrega listo para enviar. 4) Nunca crees ofertas o descuentos que no haya autorizado. 5) Tono: confiado, empático, nunca desesperado."

Herramientas y cuentas necesarias — las tres ya las conoces de módulos anteriores:

  • Evolution API — 100% gratuita y open source; se instala en Railway o Render (planes gratuitos). La cuenta se conecta escaneando un código QR, igual que WhatsApp Web.
  • n8n — n8n.io o n8n.cloud; la misma cuenta del Módulo 19. Plan gratuito suficiente para comenzar; Starter US$20/mes para uso intenso.
  • Claude API — console.anthropic.com; la misma API key del Módulo 21. Costo por tokens, irrisorio para uso personal (menos de US$5/mes para uso intenso diario).

Montar el flujo en n8n, con Claude generando el JSON:

PROMPT PARA QUE CLAUDE GENERE EL FLUJO "Genera un flujo completo para n8n en formato JSON. La automatización: cuando llegue un mensaje en WhatsApp vía Evolution API Webhook, toma el texto del mensaje, envía a la API de Claude con el siguiente system prompt: [PEGA TU SYSTEM PROMPT AQUÍ], recibe la respuesta de Claude y envíala de vuelta como mensaje de WhatsApp usando Evolution API Send Message. Credenciales: Evolution API Base URL: [MI_URL], Evolution API Key: [MI_KEY], Anthropic API Key: [MI_KEY]. Entrega solo el JSON listo para pegar en n8n."

Configurar Evolution API, paso a paso:

  1. Crea una instancia — con Evolution API instalada, en Swagger UI crea una instancia con POST /instance/create. Cada instancia conecta un número de WhatsApp.
  2. Escanea el código QR — con el número que será el asistente (usa un chip separado, no tu WhatsApp personal principal).
  3. Copia el ID de instancia y el token — la API Key generada y la URL del servidor, los necesitarás en n8n.
  4. Configura el webhook — en POST /webhook/set, pon la URL de tu n8n para que Evolution API le avise cuando llegue un mensaje nuevo.
  5. Activa y prueba — envía un mensaje desde tu WhatsApp personal al número conectado; si el flujo está activo, la respuesta de Claude llega en segundos.
✅ Buenas prácticas Usa un número secundario o chip nuevo para el asistente — nunca tu WhatsApp personal principal. Cuanto más específico el system prompt (contexto del negocio, reglas de tono, formato de entrega, ejemplos de qué sí y qué no hacer), mejor se comporta el asistente. Pruébalo contigo mismo por al menos 2 días, intentando romperlo con preguntas inesperadas, antes de activarlo con clientes. El celular con Evolution API debe permanecer siempre encendido y conectado a internet — configúralo para nunca dormir. Define siempre en el system prompt qué NO debe hacer el asistente (no dar precios ni plazos no autorizados).
⚠️ Errores comunes Usar el WhatsApp principal personal para el asistente — mezclar automatización con conversaciones personales genera confusión y riesgo; escribir un system prompt muy genérico; no probar antes de activar con clientes reales; dejar que el celular se apague (Evolution API deja de funcionar sin el celular encendido y online); y no poner límites claros en lo que el asistente puede responder.
— Anotado por EDI: si el celular se apaga o se cae el internet, el asistente se detiene. Para uso profesional, usa un celular dedicado que se mantenga siempre cargado y conectado.
