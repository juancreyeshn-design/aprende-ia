🎛️ Módulo 23. APIs especializadas: audio, imagen, voz y web

📘 Concepto

Claude, ChatGPT y Gemini son excelentes para escribir texto y razonar, pero no son las herramientas correctas para todo. Existen APIs especializadas — cada una entrenada para una sola tarea específica: transcribir audio, leer imágenes, generar voz humana, buscar en internet en tiempo real, leer PDFs, traducir, generar imágenes o analizar el sentimiento de un texto. Usar la API correcta para cada problema, en vez de forzar todo a través de un solo modelo de lenguaje, es lo que separa una automatización que funciona bien de una que da resultados mediocres.

💡 La mayoría de estas APIs se combinan con Claude o GPT en el mismo flujo: la API especializada convierte el dato (audio, imagen, PDF) en texto o en otro dato estructurado, y Claude o GPT lo interpreta y genera la respuesta final. Son piezas complementarias, no competidoras.

⚡ Caso aplicado: las 8 APIs más útiles para el día a día

01 · TRANSCRIPCIÓN DE AUDIO Y VIDEO — Whisper API (OpenAI) Transcribe cualquier audio o video a texto, en más de 50 idiomas, identificando distintas voces. Costo: US$ 0,006 por minuto de audio — una reunión de 1 hora cuesta cerca de US$ 0,36. Ejemplo: reunión grabada de 1 hora → Whisper transcribe en 2 minutos → Claude genera resumen ejecutivo, decisiones y próximos pasos a partir de esa transcripción. 02 · LEER IMÁGENES Y DOCUMENTOS — Vision API (Anthropic/Claude y OpenAI/GPT-4o) Analiza imágenes y extrae la información que se le pida: lee documentos fotografiados, interpreta gráficos, identifica productos. Una imagen equivale a cerca de 1.000 tokens (~US$ 0,003 por imagen). Ejemplo — el más útil para trabajo contable: foto de una factura → Vision extrae empresa, fecha, artículos y totales → se guarda automáticamente en la hoja de gastos. 03 · GENERAR VOZ HUMANA — ElevenLabs API Convierte texto en voz humana realista, con más de 1.000 voces y clonación de voz propia. Plan gratis con 10.000 caracteres/mes; Starter US$5/mes con 30.000 caracteres (≈1.000 caracteres = 1 minuto de audio). Ejemplo: guion escrito → ElevenLabs genera el audio → se combina con imágenes para un video. 04 · BUSCAR EN INTERNET EN TIEMPO REAL — Serper API Conecta la IA a Google para investigar con datos actuales, no solo los del entrenamiento. Plan gratis con 2.500 búsquedas/mes; plan básico US$50/mes con 50.000 búsquedas. Ejemplo: Serper busca noticias de un competidor → Claude recibe los resultados y genera un resumen de inteligencia competitiva. 05 · LEER Y PROCESAR PDFs — Claude (nativo) y PDF.co Extrae texto de PDFs, incluso escaneados por OCR — Claude ya acepta PDFs directamente por API. Ejemplo — muy relevante para contratos y expedientes: 50 contratos en PDF al mes → el flujo lee cada uno → Claude extrae cláusulas, fechas de vencimiento y montos → todo va a una hoja de gestión de contratos. 06 · TRADUCCIÓN PRECISA A ESCALA — DeepL API Traducción de alta calidad en más de 30 idiomas, mejor que Google Translate para contenido profesional. Plan gratis con 500.000 caracteres/mes (~100 páginas); plan Pro desde US$6,99/mes. Ejemplo: contrato recibido en inglés → DeepL traduce → Claude analiza las cláusulas ya traducidas. 07 · GENERAR IMÁGENES PROGRAMÁTICAMENTE — DALL-E 3 API (OpenAI) Genera imágenes a partir de texto dentro de un flujo automático, sin abrir ningún sitio web. Costo: US$0,04 por imagen (1024×1024) — 30 imágenes al mes cuestan US$1,20. Ejemplo: calendario de 30 temas en Sheets → Claude genera el prompt de imagen → DALL-E la genera → se guarda en Drive lista para usar. 08 · ANALIZAR SENTIMIENTO A ESCALA — Claude (vía API) Clasifica cientos de reseñas, comentarios o correos por sentimiento y motivo principal, de una sola vez. Costo: 500 reseñas cortas cuestan cerca de US$0,50 en total. Ejemplo: 500 reseñas de Google → Claude analiza cada una → hoja de cálculo con sentimiento, calificación 1-5, problema o elogio principal y categoría — para ver patrones y saber dónde mejorar.

Dos prompts listos para copiar y adaptar (los más útiles para una práctica contable o profesional):

EXTRAER DATOS DE UNA FACTURA (Vision, vía API) "Analiza esta imagen de factura y extrae lo siguiente en formato JSON: company_name, tax_id, date, items (arreglo con descripción y valor), subtotal, taxes, total. Si algún campo no es visible, devuelve null." EXTRAER DATOS DE UN CONTRATO (Claude con PDF, vía API) "Lee este PDF de contrato y extrae lo siguiente en JSON: contract_type, parties (arreglo con nombre y rol), start_date, end_date, total_value, payment_terms, main_obligations (lista), penalty_clauses (lista) y renewal_conditions. Si un campo no está presente, devuelve null."
✅ Buenas prácticas Usa cada API para lo que fue creada: Whisper para audio, Vision para imágenes, DeepL para traducción — mezclar tareas genera resultados pobres. Aprovecha los planes gratuitos generosos (DeepL 500.000 caracteres, ElevenLabs 10.000 caracteres) antes de pagar cualquier suscripción. Envía siempre imágenes nítidas a la Vision API — la calidad del resultado depende de la calidad de la foto. Cuando el resultado de una API va a otro sistema del flujo, pide siempre un formato fijo como JSON.
⚠️ Errores comunes Usar Claude para todo, incluso para transcribir audio (Claude no transcribe audio — eso es trabajo de Whisper); no aprovechar los planes gratuitos antes de pagar; mandar imágenes de baja calidad a la Vision API; no especificar el formato de salida en el prompt de la API; y olvidar que la API de búsqueda (Serper) cobra por cada búsqueda — hay que programar el disparador para no activar búsquedas innecesarias.
— Anotado por EDI: cada API tiene una especialidad. Usar la incorrecta genera frustración y un resultado malo — identifica primero qué tipo de dato necesitas procesar (audio, imagen, PDF, texto) y elige la API hecha para eso.
